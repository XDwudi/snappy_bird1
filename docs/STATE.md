# 项目现状

更新时间：2026-09-30。当前为 **v1.8.1 测试候选**，基于v1.8.0继续开发，未完成手机验收。微信上传由用户手动完成。

## 当前内容

CommonJS/Canvas微信小游戏；六章、73张卡、六派系、击杀/生存双通关、六章全通后的无尽模式，等级无限、得分双倍。

1.8.1响应“首局全通、无尽不易死亡”反馈：提高开局/章节/Boss压力，固定Boss礼包经验，收敛经验复利和无尽恢复循环。六Boss分别有破根、诱撞、孵化卵、蓄热、开阀、顺序节点六种破解机制，18个独有出招模式。普通怪靠近管道出口；护航炮艇与唤天气灵伴飞、释放技能、击杀领奖。玩家生命统一红心/暗心/黄色临时心，Boss保留图形血条。

- 71项机制回归通过（15+12+21+23），覆盖36招/三屏、六章奖励链、机关防重、精英/天气、无尽恢复跨来源限制、连续碰撞、图形心。
- 43个运行文件Node语法检查通过，无可选链/空值合并；普通游戏和天气模拟脚本可完成。Canvas真实渲染已检查六章、精英和320px短屏红黄心。
- 120局无尽注入构筑压力测试全部结束，其中防御构筑中位7.3分钟；其他构筑脚本更早死亡。仅33/120样本落在5–20分钟，不能宣称真人无尽时长目标达标。用户反馈优先，旧1.8.0模型不再作为真人平衡达标依据。
- 100局早期脚本：25局到达Boss，11局生存通关；192场注入构筑Boss测试记录两条通关路线。这不是自然抽卡的真人胜率，具体假设/原始文件见迭代文档。

## 代码入口

`game.js` → `game/core/Game.js`。`CampaignConfig.js`为章节与招式配置；`BossPatterns.js`/`BossHazard.js`为预警与攻击，`BossMechanics.js`为六种破解机制，`BossArt.js`为主体形象。`EliteMonster.js`为两种精英，`SpawnSystem.js`决定遭遇，`WeatherSystem.js`处理天气精英修正。`AbilitySystem.js`集中经验属性与跨来源恢复限制，`EndlessScaling.js`为时间曲线。
