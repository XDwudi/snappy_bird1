# 项目现状

更新时间：2026-10-02。当前为 **v1.8.3 美术改造测试候选**，手机验收尚未完成。微信上传由用户手动完成。

## 当前内容

CommonJS/Canvas微信小游戏；六章、73张卡、六派系、击杀/生存双通关、六章全通后的无尽模式，等级无限、得分双倍。

1.8.3按用户确认的首版像素冒险风格重做六章场景、柱体材质、小鸟、普通怪、四精英、六Boss/机关、拾取物和武器；首页/HUD/选卡/教学/转场/结算及全套天气与战斗特效统一。73张能力使用明确的图标映射与派系配色。短屏可滑动查看3/4/6个完整卡面，拖动不误选，底部内容避开系统安全区。

继承1.8.2平衡修订：拍翅固定，轻羽改善下落，顺风等成长转为火力；前20级经验费用不变、之后二次费用，加成加算并高倍率递减；天气减负与增益可共存。六章最迟140–190秒迎战，Boss血量135–1750、生存时限100–190秒、导弹每3秒供给；四精英和后期穿盾攻击保持原数值。
