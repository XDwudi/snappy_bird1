## 产品与代码

微信小游戏，纯CommonJS/Canvas，单指Flappy Bird飞行+roguelike成长。61张卡（普通10/稀有20/珍贵20/史诗11），草地和沙漠两章，HP/护盾/天气/怪物/多武器/双通关Boss。仅持久保存最高分；音效、社交、排行榜未实现。仍按60fps逻辑帧计时，手机低帧率时秒数会变慢。

入口`game.js`→`game/core/Game.js`；难度和战斗参数在`GameConfig.js`，卡牌在`AbilityConfig.js`。新增`CombatSystem.js`管理羽刃/风环/反击，`SandWall.js`管理沙墙，`CombatIcon.js`绘制新技能图标。
