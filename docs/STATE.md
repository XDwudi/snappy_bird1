# 项目现状

更新时间：2026-10-01。当前为 **v1.8.2 测试候选**，未完成手机验收。微信上传由用户手动完成。

## 当前内容

CommonJS/Canvas微信小游戏；六章、73张卡、六派系、击杀/生存双通关、六章全通后的无尽模式，等级无限、得分双倍。

1.8.2响应Boss偏弱、炸管拖延和技能难懂的反馈：后期多轮弹幕与有紫色预警的穿盾区域攻击；Boss血量120至1350、生存时限100至190秒、导弹每3秒供给。六章最迟140至190秒迎战，重赛20管或35秒，避免无限发育。第二章砂瀑改为横向沙幕缺口。入场两行教学、战中机关进度、按波次出现的预警，使六种破解方式更明确。

四精英为护航炮艇、唤天气灵、棱镜哨兵、孢雷水母，后两种第三章开放，按章节与无尽时间成长，精英出场给导弹反击机会。玩家生命仍为红心/暗心/黄色临时心，剩1红心出现红框与生命危险提示。

## 代码入口

`game.js` → `game/core/Game.js`。`CampaignConfig.js`为章节、时限、Boss与精英数值；`BossPatterns.js`/`BossHazard.js`为预警与攻击，`BossMechanics.js`为六种破解机制，`BossArt.js`为主体形象。`EliteMonster.js`为四种精英，`SpawnSystem.js`决定遭遇与供给，`WeatherSystem.js`处理天气精英修正。`AbilitySystem.js`集中经验属性与跨来源恢复限制，`EndlessScaling.js`为时间曲线。
