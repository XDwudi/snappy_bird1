# 项目现状

更新时间：2026-10-03。当前 **v1.9.0 构筑与玩法体验**，基于v1.8.6（14ec970）。开发与离线回归完成，手机和真人体验验收待完成；微信上传由用户手动完成。

## 当前内容

CommonJS / Canvas 2D微信小游戏，无npm运行依赖。六章Boss、四精英、资源异步分包。73历史卡ID迁移为11组件＋60被动＋2基础UI，实际71张卡；单局3组件＋6被动、1主专精、最多2进化。开局羽刃Lv1，旧派系自动叠层收益取消。

升级卡牌只预选，固定底部按钮确认；滚动、跨面板触摸、多指及开窗短期锁保护幸运六卡场景。每局2重掷、2次章间构筑调整；完整事务检查前置/等级/投资/专精/进化，并保留一次性资源账本。

六种机关分别为永久拆根、追踪后锁定诱撞、封路/追踪双卵、缓移暖流、进入边沿触发双阀、三节点永久断路。Boss奖励仅一次成长；普通选择至少6秒间隔，多余经验保留到下一章释放，六章累计上限35次成长。满配只允许有限突破，之后即时补给。六章后主动结束或继续无尽。

章间续局保存候选及随机状态；离开休息点即清除旧检查点，不提供战斗中断点恢复。新旧最高分分开保留。固定60Hz逻辑适配不同渲染帧率、后台暂停；本地战报记录构筑、真实事件、死亡原因和各阶段时长。

## 验证

- 74项通过：32新规则、12旧修复生命周期、10弹丸、16物理路径、4多屏Canvas检查；运行JS语法/打包通过。
- 108场等投资Boss对照、12组完整成长探针执行完成；两者屏蔽扣血以隔离相关指标，不能当真人通关率。
- 48局自然模型保留真实伤害，最远第3章，没有六章完整胜利；早期失败、真人长局和路线平衡待实测。固定拍翅模型已修正偏飞阈值，旧数据保留。
- 完整成长探针首章7–8次、六章35次，含每次3秒模拟读卡约17.0–19.6分钟；未测真人含无尽P90。
- 主包约2.91MB、资源分包约3.82MB；手机≥30fps/2秒首屏未验收。未上传微信。
