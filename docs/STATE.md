# 项目现状

更新时间：2026-09-18。当前为 **v1.6.0 测试候选**，未宣称正式发布或真机验收通过。

## 产品与代码

微信小游戏（不是 WXML 小程序），纯 CommonJS / Canvas，单指 Flappy Bird 飞行 + roguelike 成长。当前 61 张能力卡，普通10/稀有20/珍贵20/史诗11；草地与沙漠两章。具有 HP、护盾、三选一、天气、怪物、导弹、Boss 双阶段和章节礼包。只持久保存最高分；音效、社交和排行榜尚未实现。

入口 `game.js` → `game/core/Game.js`。数值集中在 `game/config/GameConfig.js`，卡牌在 `AbilityConfig.js`。生成/章节/能力/经验/天气分别在 `game/systems/`。游戏仍按60fps逻辑帧计时；真实低帧率时秒数会变慢，需真机验证。

## 实测与限制

- 375×667，三种固定种子共300局，同一管道操作模型：第一章 Boss 到达率 **14.3%→65.0%**，前30秒死亡率 **14.0%→3.7%**，生存中位 **46.6→85.1秒**。
- 390×844：300局，到达率68.7%，前30秒死亡2.7%；320×568：300局，到达率64.0%，前30秒死亡3.7%。拟人模型不主动躲弹，不能拿其通关率当真人 Boss 胜率。
- 15项机制回归通过；Boss 模拟11项旧机制及当前硬指标通过；成型导弹击杀中位23.8秒，满配17.8秒。
- 历史 `test_builds_v140.js` 仍失败：构筑差距1.4倍、血契中位72.9秒/离散度1.66未达旧目标；随机中位104.2秒超旧78秒上限，后者与本轮降低难度目标冲突，不为通过旧上限重新加难。
- 微信工具版本2.02.2609102 Nightly可打开项目，但模拟器报 `Cannot convert undefined or null to object`，预览获取权限时 `ECONNRESET`（TLS建立前断连）。尚未得到游戏启动日志，不能确认是工具还是项目兼容性原因；未产出有效新二维码。
- Canvas 各主状态通过 mock 调用验证，**没有完成像素画面或手机触控验证**。完整日志见本轮迭代和测试输出。
