# ADR-003：两章首版及本地试玩

- 日期：2026-09-18
- 状态：实施；玩法初始数值仍待真人验证
- 背景：用户要求立即扩充技能、章节天气、每章精英/Boss与过关大奖，并开始首版。

沿用TypeScript/Canvas和微信小游戏适配层，不增加依赖或引擎。首版范围改为两章、39技能、6遗物；长期库78项。
ADR-002的固定60Hz/纯逻辑/独立世界与抽卡随机流已实施；未用到战斗随机的部分保持确定性，表现不消费领域随机数。
不在首版引入存档格式或完整回放文件。bootstrap以固定步长、每帧最多5次更新运行，超过200ms中断暂停，后台恢复需手动继续。
副武器60%效率、至多两武器；首版常规辅助卡不限制8槽，控制在每章最多10次升级，作为快速试构筑方案。长期槽位规则需重新评估。
新增仅本机的浏览器wx适配预览，复用原始构建包；预览脚本在scripts内，不能向玩法层引入DOM。路由仅首页和game.js，不暴露个人配置。
真实AppID只存在gitignore本地配置/产物；提交前与CI扫描源码文档，不上传本地dist。

微信Nightly故障时继续本地验证，不标记微信平台验收完成。上传为开发测试用途，不代表正式发布准备完成。

官方项目配置核对来源：[微信官方小游戏示例](https://github.com/wechat-miniprogram/minigame-demo/blob/master/project.config.json)。仅采用项目字段结构，不复制示例AppID。
