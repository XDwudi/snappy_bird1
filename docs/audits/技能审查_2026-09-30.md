# 技能实效审查 · v1.7.0

基于9月18日全61卡实现审计，结合本轮手机反馈复核低价值技能和Boss适用性。代码检查与脚本验证不能代替真人逐卡试玩；本轮不宣称61张卡已完全平衡。

## 判定方法

一张卡至少应能带来一种可感知的选择：更安全的路线、不同的攻击方式、可观察的资源收益或明确的高分目标。触发条件应在实际场景中出现，收益与操作成本应匹配。脚本持卡相关性不能直接当作因果强度，信息卡尤其如此。

## 已处理

| 技能 | 实际问题 | 本轮处置 |
|---|---|---|
| 二段跳 | 本来即可无限拍翅；双击把速度设为普通拍翅的0.85倍，没有新增动作能力，反而制造隐式力度变化 | 移除技能、CD和双击检测，统一普通拍翅 |
| 羽舞 | 为低价值二段跳追加擦边窗口；增加学习成本且依赖别的卡 | 随二段跳移除 |
| 经验银行 | 上轮虽已修正为额外储蓄，但低额延迟经验与贪婪/经验共鸣定位重复，收益难以感知 | 移除完整银行系统和UI，保留正常经验与顿悟 |
| 时间扭曲 | 只检测近管道，而Boss战没有管道，战斗场景缺少实际触发入口 | 补充近怪物、弹幕、沙墙、俯冲检测，共用CD；Boss弹幕也受减速 |
| 时之晶 | 寄生时间扭曲，原Boss战冻结能力几乎不可自然触发 | 随触发入口修复，冻结移动但不取消碰撞；已有前置过滤保留 |
| 新疾风羽刃 | 提供低频自动直射，让玩家在飞行中选择对准敌人 | 等级提升射速，不改变拍翅；怪物1伤/Boss2伤，破绽额外+1 |
| 新风环护卫 | 把可见充能转化为拦截与反射 | 拦1枚后8/6/4秒恢复，不变成永久护盾；不挡环境墙或本体 |
| 新逆羽反击 | 防御资源损失转化为短暂输出机会 | 消耗盾/羽盾/临时HP/HP才触发；4秒CD；Boss每轮只计一次基础伤害，卡面写明 |

三张新卡均无需前置；不会抽到“先拿另一张才有效”的空卡。先知协同表删除旧ID，加入反击与坚韧/回响之翼的关系；注册表和全部协同/前置引用均经过断言。

## 其余重点技能的设计判断

| 技能组 | 实际作用 | 保留理由 / 限制 |
|---|---|---|
| 磁吸、补给线、拾荒者 | 获取道具；Boss战导弹补给、主动击杀后收益更直观 | 磁吸不是自动拿经验球的旧设定；现在主要吸道具。新羽刃让拾荒者不再强依赖导弹 |
| 火力覆盖、挂架、猎手标记、风暴、蜂群链路 | 追踪输出/群怪清理 | 保留；对Boss同来源45帧门防秒杀，链路对Boss只续窗不叠伤；不把三枚命中夸称三倍DPS |
| 厚皮、体魄、自愈、护盾体系 | 防怪伤/增加恢复与容错 | 在生存Boss路线仍有实际收益，未为抬高难度统一削弱 |
| 镜面护盾、铁喙 | 近距离清小怪/接触反杀 | 仍不伤Boss，明确为普通遭遇战技能；新逆羽可伤Boss，但成本与伤害方式不同 |
| 管感、先知 | 路线信息、选卡协同信息 | 信息收益无法由旧脚本衡量，不能按脚本“低生存相关性”移除 |
| 连击之心、缩小射线、锐利目光、幻影舞步、瞬移 | 管道期容错与擦边成长 | Boss清管道后部分收益暂停，但普通飞行阶段是独立有效玩法；不强行让每张卡全场景最优 |
| 轻羽、顺风、御风者 | 改变飞行轨迹与节奏 | 有操作适应成本，不视为无条件强化；本轮保持基础手感，只移除隐式双击力度变化 |
| 贪婪、经验共鸣、顿悟 | 直接加速成长、经验爆发 | 与银行相比有即时反馈；顿悟偏向大额经验/章节礼包，前期常态收益低，继续观察而非宣称已解决 |
| 天气卡、风暴之眼 | 单天气/并发天气下生存和经济 | 风暴之眼条件较窄；保留后期定位。顺风耳×御风者、风暴之子×气候适应仍有反协同提示 |
| 旅者、章节回响、章节之主 | 跨章补给/临时升卡/章节奖励 | 首章未推进时收益少，属于投资卡；两章版本回报窗口短，后续应结合选取率决定是否延迟入池 |
| 战利品陈列 | 击杀Boss后经验与道具率加成 | 生存通关不叠层，适合进攻路线；不是所有构筑都应选 |
| 双倍积分 | 高分目标收益，最高分会保存 | 不增加生存，仍有独立追分用途；没有被错误评价为防御技能 |
| 血契、狂暴、求生本能、凤凰 | 低血高收益与补偿 | 血契仍有明显风险，旧测试中位76.6秒未达80秒下限，需手机专项验证；不掩盖已知差距 |

## 已验证的实效

真实Game测试覆盖三张新卡实际命中、经验发放、资源消耗和冷却、暂停重开、防重复通关。测试还覆盖时间扭曲在没有管道的Boss战触发、时之晶实际冻结弹幕。模拟成型导弹击杀中位24.3秒、满配17.8秒；无卡15/30局通过45秒生存，说明进攻和生存路线都存在，但不等于所有组合强度相等。

新增技能不是自动必拿：直射要对准高度，风环只能挡一枚弹幕，反击必须付出防御资源且有CD。新武器独立Boss受击门，避免一张低伤害自动卡抢占导弹的伤害结算。
