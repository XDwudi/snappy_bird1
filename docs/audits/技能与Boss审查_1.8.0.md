## 审查结论

- 12张新卡覆盖输出、持续伤害、传导、弹幕拦截、击杀回血与过管补盾；机制回归检验实际伤害/治疗/盾/冻结/冷却，而非只检验定义存在。
- 弹丸和范围伤害分开处理：范围脉冲不会再次叠毒或递归连锁；尸体/同一穿透目标不会重复领取经验。
- 新武器独立Boss伤害门，保留旧导弹；破绽加伤继续生效。
- 凤凰升级不再重置已用次数。
- 无尽末段对数突破只加武器伤害；防御恢复、过管积累与无敌窗口随时间受压，防止管道变密反过来养出无限续盾。
- 卡面为剧情基础值；无尽HUD显示全局防御恢复比例，单卡冷却/过管计数会受它影响。
- 全部旧卡仅进行分章和派系接入，未声称完成真人选取价值统计；顿悟、天气互斥、血契等长期价值仍需真机观察。

## Boss与视觉

- **古木守卫**：追风叶刃、荆棘根墙、树根横扫、孢子播散、藤蔓突进、林地复苏。P2组合：追风叶刃 → 荆棘根墙；树根横扫 → 藤蔓突进；孢子播散 → 林地复苏。
- **遗迹巨蝎**：毒尾三刺、流沙石门、地裂钳击、毒针风轮、钻沙冲撞、落岩震击。P2组合：毒尾三刺 → 流沙石门；地裂钳击 → 钻沙冲撞；毒针风轮 → 落岩震击。
- **月蚀蛛后**：蛛丝封路、月蚀射线、追魂虫群、毒卵孵化、八足回旋、暗影连刺。P2组合：蛛丝封路 → 追魂虫群 → 月蚀射线；毒卵孵化 → 八足回旋 → 暗影连刺；月蚀射线 → 毒卵孵化；暗影连刺 → 蛛丝封路 → 八足回旋。
- **冰川魔像**：冰棱扇击、冰川断层、霜线冻结、暴雪坠晶、折光冰镜、冰山推进。P2组合：冰棱扇击 → 霜线冻结 → 冰川断层；暴雪坠晶 → 折光冰镜 → 冰山推进；冰川断层 → 暴雪坠晶；冰山推进 → 冰棱扇击 → 折光冰镜。
