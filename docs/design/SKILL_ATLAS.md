# 技能图鉴 v0.2

完整内容提案，非已实现清单。所有伤害为基础伤害单位；`a/b/c` 表示三个等级，百分比默认加法。
W=武器3级，B=机制分支3级，U=功能分支2级，M=精通1级，E=武器进化1级。
本派01–06无硬性前置，但需要相应武器才生效的条目，仅在已装备该武器时入池。
M要求本派非进化等级总和≥6；E要求01三级、指定B二级及07；进化继承原武器等级但**替换**其攻击定义。
所有秒数均为游戏有效时间；同一技能及同名效果不自我递归触发。全局上限和事件归属见 BALANCE/SYSTEMS。
