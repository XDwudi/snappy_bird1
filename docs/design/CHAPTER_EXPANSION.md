# v0.3章节与创意技能扩展（本轮实施依据）

用户已要求开始开发，并补充章节天气、每章精英/Boss、大型过关奖励和更多构筑。本文件覆盖v0.2对应规则。

## 第一版范围

可玩版以两章各3分钟、总有效飞行6分钟实现。第一章晴空林地，第二章熔岩群峰；每章90秒开始一次精英遭遇，135秒进入Boss，最多战斗45秒。
升级和奖励菜单暂停计时。Boss提前击败会直接给章末奖励并进入下一章；因此熟练玩家可能提前完成，不人为等待计时器。
精英被击败后额外获得一次三选一；Boss过关回复2血、获得一件永久生效到本局结束的传奇遗物，并发放一次额外技能选择。
Boss超时撤退仍可过章但不额外回复生命，遗物保留，确保低伤害构筑有出路。章末明确区分击破与坚守。
第二章Boss完成后仍可查看遗物奖励与构筑回顾，然后结算，不设置尚未实现的下一章按钮。

## 章节天气

- 林地：前35秒晴天教学，35–55秒微风（渐变纵向风力），60–80秒阵雨（敌弹略减速、雨不伤害），其余晴天。
- 火山：前20秒熔岩晴空，20–45秒热风（更强但有2秒渐变），50–80秒火雨（显示落点预告后小型火滴下落）。
- 精英和Boss期间停止天气伤害；不叠加两种强天气；热风时扩大障碍缺口，火雨不在鸟当前位置无预告生成。
- 风不修改拍翅脉冲，仅添加有上限的加速度；雨/火雨使用不同形状、颜色、预告，不能只有换背景。
- 后续第三章星夜裂隙规划星潮、流星轨迹和镜像风；不纳入第一版冒充完成。

## 创意技能目标与实际范围

v0.2的66项长期图鉴保留，新增下述12项行为机制，完整设计库扩为78项。
第一版落地六派各01–04（24项）+通用C01–C03（3项）+新增X01–X12（12项），合计39项。
另外6件Boss传奇遗物只由章末获取，不混入39项常规技能池。不是把78项设计全部声明为已实现。
原型先不接入v0.2进化和共鸣专属卡，但新增技能本身允许跨流派搭配；无基础武器依赖的创意卡各派均可拿。

## 六件传奇遗物

每次Boss给三个不同候选，已获得的遗物不再次出现。一次选择即改变后续玩法，不靠小百分比充数。

| ID  | 遗物     | 改变                                                                       |
| --- | -------- | -------------------------------------------------------------------------- |
| R01 | 双重羽冠 | 每3次主武器攻击再释放一次50%伤害回声，不再次触发武器/技能计数              |
| R02 | 不灭火种 | 当前和上限生命+2；每章首次致命伤以1血存活并清空附近敌弹                    |
| R03 | 风暴电池 | 所有精准门为下一次主武器积累8伤，最多3层；雷系与穿云独立但消费同一直接攻击 |
| R04 | 霜镜圣杯 | 每12秒清除3枚普通敌弹；每清除6弹回复1血，每章最多2次                       |
| R05 | 铁翼王印 | 护盾上限仍3；每10秒补1点盾；每次护盾击破向前方最多3敌反击8伤               |
| R06 | 万象种子 | 选择后立即给所有已拥有且未满级的常规技能升1级，不突破满级，并回复1血       |

## 可玩性验证标准

必须实际验证：六派都能起手、至少两种技能组合改变玩家选择、两章天气确实不同、每章只生成一个精英和一个Boss、奖励足够可见。
用固定seed跑保守/普通飞行策略，记录首次升级/死亡/过章/敌弹上限和技能触发次数。机器人能通关只能证明流程，不证明真人觉得有趣。
检查新技能触发有冷却、明确反馈和无递归；真实玩法反馈以用户首次试玩为下一轮调优输入。
新增39项是首版内容容量，不承诺一次6分钟局能选完；常规升级每章8次，精英/Boss额外各1次，鼓励重玩换构筑。
