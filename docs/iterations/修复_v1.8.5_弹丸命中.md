# v1.8.5 弹丸命中修复

日期：2026-10-03。基于 75e692a，版本号保持 1.8.5。

玩家反馈子弹穿过怪物却不造成伤害。本地确认了两个可复现问题：精英绘制为 60×58，受弹判定只有 46×38；在中心上下 25 px 的可见身体位置射击，原羽刃和导弹均不命中。另一个问题是只检查每帧终点，导弹与高速移动怪物相向而过时，上一帧和下一帧都可能没有矩形重叠。

## 修复

普通怪和精英提供独立受弹范围，覆盖可见身体/翅膀及轻微摆动。精英创建后立即同步盒子，避免首帧保留普通怪高度。玩家撞怪时仍用原来的碰撞判定，不增加身体接触伤害范围。

每个有效 Game 帧记录目标位置；羽刃、元素弹与导弹记录发射物上一位置，使用相对运动线段与扩展矩形的相交检测。冻结帧也刷新快照，防止重复使用旧位移。导弹击中上下管体使用同样连续判定，经过中间缺口仍不会炸管。

新武器按沿路径的先后顺序结算。普通弹只击中最近目标；沙矛可以在同一帧穿过多个目标，每个目标只记一次命中。既有毒伤、冰枪减速、雷链、击杀奖励、Boss 同来源 45 帧受击间隔均保留。
