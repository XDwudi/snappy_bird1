# v1.8.2：Boss压力、遭遇时限与可读性

日期：2026-10-01。基于玩家手机反馈实现，本版仍需手机验收；不执行微信上传。

## 设计目标

保留运气好、构筑成型时的强势体验，同时消除炸管无限延迟Boss的额外发育。难度主要来自后期多轮弹幕、穿盾区域和更长的战斗，不追踪预警结束后的玩家位置。六种机关保留各自规则，补齐操作说明和即时进度；不是把所有Boss换成同一种攻击。

管数与最短时间同时满足即可开战；未满足也在最迟时限强制迎战。炸掉管道不伪造通过数。剧情战败20管或35秒后重赛，先到为准。暂停、选卡、出场与转场不累计有效时间。HUD显示最迟开战倒计时。

章节滚动速度加成为每章下标×0.36，缺口修正为下标×−9px，第一章管道基础参数保持原值。Boss半血或生存时限35%进入P2；两者先到。起手/恢复间隔缩短。基础弹速3.85至5.70，战斗进行37.5秒后达到额外25%上限；无尽另乘时间压力。

普通弹射招式按章节下标生成 `1+floor(tier/2)` 轮，P2再加一轮，每轮相隔42帧。第四章以后P2最多4轮。招式保持主题轨迹：飞种折返、虫群/卵巢、冰棱反弹、熔核裂变、磁极与机核扇形射击。原先向右飞离玩家的机核环射改为面向玩家的七路放电。

每招按危险物完整寿命（包含分裂子弹）安排下一招，避免加密后无预警叠招。延迟波次只在自己的预警窗口内显示，不再同时绘制几轮未来安全框。实体上限仍为96。

## 公平躲避与穿盾

第二章砂瀑改为三道横向沙幕，154px缺口每次换位48px，适配固定X、只能上下移动的操作。第五章阀口喷发改为有缺口的三次区域喷发，移除“侧移”提示。第六章磁轨也限制缺口在可操作范围；短屏保留上下路线。

第四章及以后，冻层、横向射线、阀口喷发、磁轨与部分环境墙具有穿盾属性。紫色攻击区域、菱形标记、屏内“穿盾”文字和HUD提示共同标识，至少90帧（60fps时1.5秒）预警。穿盾只跳过羽盾和普通盾，不消耗这些盾；仍保留厚皮概率格挡、受击无敌、时间扭曲与凤凰。伤害先扣黄色临时生命，再扣红心。区域攻击本来就不被风环或普通清弹消除。

无尽随机Boss沿用第六章弹速/阶段/穿盾资格，并继续随无尽时间增压；生存时限由90秒改为150秒。

## 击杀路径与指引

每场进战即供导弹，此后3秒一次（原5.5秒）。已有导弹道具时保持就绪，拾取后马上补发，不再额外等一个周期；仍只保留一枚保底道具，随机掉落独立。延长生存通关时限，为击杀和破解机关留时间，保留无火力构筑的生存出口。

入场准备延长到3秒，显示每Boss两行教学；飞入阶段继续显示。战斗HUD显示实际剩余树根/紫卵、蓄热/开阀进度、热量或当前节点；巨蝎冲锋锁定后明确要求离开红带。

- 古木：先对准两枚树根发射，破根后集中攻击失甲本体。
- 巨蝎：到绿框高度诱导瞄准，锁定后上下离开，让巨蝎撞柱。
- 蛛后：对准紫卵阻止孵化，减少卵巢散射的射口。
- 冰像：交替在绿框蓄热三次，碎冰后强攻，同时避开穿盾冻层。
- 地龙：交替开阀降热，满热会追加地火，三次开阀引爆熔核。
- 机核：按发光顺序攻击节点，完成断路后核心失防。

## 精英与低生命

旧版只有炮艇、天气灵，并非另外几种没刷到。本版第三章起加入棱镜哨兵（上下双源交叉弹）与孢雷水母（锁定高度的膨胀孢雷），四种独立轮廓。按固定序列轮换，25秒检查周期最多连续两次未遇到即保底候选，仍需怪物空位，同屏最多一只。后两种第三章后解锁，序列跨章节保留，重新开始清零。

精英HP采用章表，不再将普通怪×精英倍率×二次倍率叠乘。伴飞时间从12秒增长到17秒；炮艇弹数2至4，弹速3.2至4.3，射击间隔150至100帧。精英过管窗口暂缓出招，90帧出场保护不变；水母孢雷预警90帧。无尽精英HP为 `96×(1+分钟/3)^2`。天气灵沿用叠加天气、击杀快速驱散机制。

精英出场时，若场上无导弹道具，在玩家前方给一枚导弹，提供反击机会；击杀奖励与防重逻辑沿用上一版。不同构筑的击杀能力仍有差异。

剩1红心时显示红色边框、缓慢呼吸光晕和“生命危险”，不遮挡中央区域，不以数字代替心形。黄色临时生命不取消低红心提醒，恢复红心后解除，选卡/重开状态按现有流程处理。
