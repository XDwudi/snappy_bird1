# v1.8.2 成长与操控平衡修订

2026-10-02。按用户要求继续使用1.8.2版本号，基于提交272a1c2修改。微信上传仍由用户完成。

## 问题与取舍

旧版拍翅速度同时乘顺风、强化、狂暴与风暴之子，轻羽又降低重力。用满级四卡、10层强化、1红心和天气活跃构造极端组合：初速度从−8变成−43.68，单次点击理论上升1862.60px，远超手机屏幕高度。旧版高经验构筑还能把倍率叠到17倍以上，后期大量升级，构筑差异逐渐消失。

本次保留起步成长、随机成型和持续火力，把收益转到攻击频率与下落容错；收敛经验滚雪球。Boss继续加强，普通怪物与精英的血量不追加上涨，保留成型后的清怪体验。现有73张卡保留身份和派系，重做互相冲突或放大操控风险的效果。

## 操控与技能

拍翅初速度固定−8，上升阶段不吃轻羽、顺风、强化、狂暴或风暴之子的乘区。基础无风单次上升约67.15px，原有点击节奏不变；雨天仍保留其环境重力作用。风不再直接多处修改速度，统一进入Bird物理更新，向上风最多抵消25%重力、向下风最多增加35%，不会反转净重力。

|技能|修订后的实际用途|
|---|---|
|轻羽|仅下落阶段重力−6%/级，最大落速−5%/级；满级落速从12降至9，不增加起跳高度|
|顺风|羽刃/元素自动武器间隔−3%/级，移除上升力增益|
|狂暴|1红心时上述武器间隔−8%/级，得分增益保留；血契时两种增益减半，不再改变飞行或经验|
|风暴之子|天气期间上述武器间隔−4%/级、得分+20%/级，不改变飞行或经验|
|普通强化|每层上述武器间隔−2%，经验/得分原有对应收益保留；不改变飞行物理|
|御风者|有风时每5/4/3秒发双羽刃，怪物1/2/3伤、Boss每轮2/3/4伤；保留同来源Boss伤害间隔门。移除风向翻转和助推|
|气候适应|风力、雨重力与危险冰雹密度−15%/级；不缩短天气，保留天气构筑增益窗口|
|顺风耳|减风效果保留；当前风已驯化时改为武器间隔−3%/级，天气消失后结束|
|雨衣|减积水效果保留；当前雨已驯化时改为武器间隔−3%/级，天气消失后结束|
|风暴驯化|风不再推动玩家，雨不加重力，冰雹无伤并保留原经验概率；减负卡不再作废|
|冰晶护体|驯化冰雹或定风珠免疫期间仍可转盾；满盾不消耗冷却，无尽恢复间隔拒绝时不虚报增盾|
|顿悟|单次入账能支付当前级+下一等级半价时连升，最多3次；赋予实际折扣，避免只是重复普通升级逻辑；不作用于Boss定额礼包|

攻击间隔加成相乘，最低保留基础间隔的45%。适用于疾风羽刃、种子、沙枪、冰枪、寒晶、熔核、奇点和御风双刃等CombatSystem自动武器；不改变导弹补给/连发节拍、防御冷却或敌方时间。面板统一更新文案，移除旧“反协同/已驯化作废”标记。

冰雹被驯化后不再因气候适应/风暴之眼降低资产密度。普通冰雹转盾仍遵守原伤害链，恢复受限且转盾失败时继续后续受击逻辑，不制造免费永久挡伤。

## 成长节奏

升级费用为：`ceil(18 + 12×(等级−1) + 0.9×max(0,等级−20)²)`。前20级不变，等级不封顶。

|当前等级|旧版费用|本次费用|
|---|---|---|
|20|246|246|
|40|486|846|
|60|726|2166|
|100|1206|6966|

贪婪、经验潮汐、风暴之眼、血契、成长祝福、战利品和森芽派系的经验加成改为加算。倍率超过4后渐近6倍：`4+2×(1−exp(−(倍率−4)/2))`。共鸣、擦边等来源奖励保留，Boss定额礼包不吃倍率、共鸣或顿悟。经验浮字显示实际到账值，避免看见的数字与经验条不一致。

这会减少后期选卡频率，并让有限升级更有取舍；不削已有武器伤害，不按玩家即时DPS追涨敌人血量。强组合仍然有更密集的输出。

## Boss进一步增强

六章HP由120/200/340/540/880/1350提升到 **135/235/410/680/1120/1750**。基础弹速4.0至6.0，缩短休息与恢复。第四章起P2再加一轮齐射，后期最多五轮，轮间隔从42缩短至36帧。各章专属轨迹、破解机关、击杀/生存通关仍保留；穿盾区域至少90帧预警，后续波次按窗口显示。

开战时间上限、导弹供给、生存时限沿用10月1日版。无尽随机Boss引用最新第六章基础HP，继续按时间增长；不额外缩小既有安全缺口。

手机重点：是否仍出现技能导致的单击冲顶；后期能否持续清怪同时感到Boss威胁；升级间隔是否过长；驯化/减负/天气输出卡同时持有是否易懂。后续优先根据这四类反馈微调，不再用拍翅幅度充当成长奖励。
