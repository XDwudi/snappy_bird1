# v1.8.5 · 视觉辨识与反馈

2026-10-03，基于 main / 0903313。用户要求先保证“是什么、在做什么、还剩多少”一眼可读，护盾、天气、导弹为例，审计范围覆盖全套战斗显示。继续使用已确认的像素冒险风格及四图集；本次只改绘制与提示，继承1.8.4战斗数值、碰撞范围、掉落、天气物理及随机序列。

## 审计与修改

| 范围 | 问题与处理 |
| --- | --- |
| 普通护盾 | 小圆点不能数层数。改为一层一个完整同心圆，深色描边配冰蓝/浅白线；0–7层逐层绘制；顶部常驻“护盾 当前/上限”。无半透明实心罩。 |
| 羽盾、复活 | 原来图标加倍数不明确，改为“羽盾×N / 复活×N”；普通盾、羽盾和凤凰次数不混算。 |
| 护盾反馈 | 首次提示“每圈护盾可挡1次碰撞”；抵挡/弹开显示余层。拾取补给后按实际状态报告补盾、已满、补给冷却或溢出转临时生命，不再满盾也报+1。 |
| 环绕守卫 | 取消与护盾相似的整圈；使用移动羽刃及短金色尾迹，未充好时变暗并显示小进度条。 |
| 磁吸、时间扭曲、风暴之子 | 原来的多种常驻圆环容易混同护盾。分别使用向内箭头、屏幕边缘时钟、两侧闪电；扩散冲击波/擦边/复活保留短暂动画语义。 |
| 下雨 | 原浅色细雨线对天空对比弱，且起雨时战区长时间无雨。改为24–48条有深浅轮廓的落雨和轻微冷色背景；从触发即覆盖战区，甩水保留溅水。 |
| 停雨、Boss天气冻结 | 落雨只在active期间显示，停雨仅保留残水/甩水。渲染使用帧钟，Boss冻结天气持续时间时仍有动画；底栏显示“持续”，避免假倒计时。 |
| 风 | 原短寿命粒子停在边缘，横风却显示竖向箭头。改为5–9条分布式箭头，按上/下/左/右实际方向流动；底栏写明方向、横风滚动加/减速、时间。 |
| 天气状态 | 显示积水百分比、残水、拍翅甩水，以及“免疫/驯化”；免疫与驯化时不再显示仍被风加速的误导文案。天气底栏优先于被动技能列表。 |
| 道具 | 五类使用不同形状及两字标签：导弹、回血、护盾、经验、减速。导弹有红弹头、白弹身、尾翼和尾焰；shield_pack不再使用节点图。经验用XP晶体，减速用时钟，补给边框与敌弹分开。 |
| 73张卡 | 全量重审显式映射，保留卡名/完整效果文字。磁吸用马蹄磁铁，铁喙用喙，雨衣用伞，沙矛/冰枪用矛，毒丝用毒骷髅，补给用补给箱，战利品用奖杯，导弹派生统一导弹。删除无意义二进制小点角标；大卡用加号/时钟/锁链/靶心等效果符号，小HUD只留主体。 |
| 我方与敌方弹体 | 保留我方羽刃、种子、矛形射击及导弹；敌弹改带尖刺轮廓，冰雹改八角冰块，减少与方块补给的混淆。 |
| 危险区域与穿盾 | 保留先预警再生效及绿色真实缺口；普通区域单斜纹，穿盾区域紫色交叉菱纹，使教程文案与实际纹理一致。 |
| 六章机关 | 树根改分叉根系，虫卵改卵形与孵化进度条，开阀用阀轮；保留按序数字节点、岩柱、蓄热绿框与进度。改变形状不改变受击框/机关坐标。 |
| 普通怪、四精英、六Boss | 保留已有可辨识图集、名称、血条、攻击/易伤提示；精英伴飞剩余时间从圆环改为血条下方细进度条。 |
| 层级和布局 | 雨/风在可攻击和可拾取对象下方，实体冰雹保持前景；顶部仍为68px信息带，底栏仍限于地面和安全区。密集Boss/天气文案实测至少9px；浮字继续避让目标。 |
| 其他UI | 检查红心/黄心、经验/等级、六章场景、Boss教学、3/4/6选卡、滚动与按钮、转场、复活、无尽和结算。现有明确表示保留；新图标共用同一套映射。 |
