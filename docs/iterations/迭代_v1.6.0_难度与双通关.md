# v1.6.0 测试候选：难度与 Boss 双通关

日期：2026-09-18。用户反馈手机首章难以到达 Boss，明确本轮难度/技能审查/Boss 双通关，下轮才加武器。旧 v1.6 章节扩展计划延期。

## 难度方案

保留重力0.45、拍翅-8、基础HP2及60fps逻辑帧。核心问题不仅是间隙小：原版每根管道独立抽取全屏高度，在长屏上产生大幅折返；前60秒同时加速、缩缝、撤销新手加宽，三项叠加过快。

管道中心受上下边界和相邻高度双重约束，开局围绕鸟的初始高度生成；Boss 后重新以鸟的位置接续。缩小射线在同一中心向两侧展开，最大间隙受屏幕可用高度限制。修正第一章 reset 未注入章节生成配置的问题。

## Boss 规则

- 第一章有效战斗45秒、第二章60秒；或把既有 HP36/45打空，提前结束。
- HUD 同时显示血量和剩余生存时间。计时不包含入场、转场、选卡、复活动画；减速/时之晶不延长生存目标。
- 两种通关均发原章节礼包（100分、三级所需经验、奖励卡、祝福），转入下一章；击杀才增加讨伐徽章/战利品陈列。结算页区分生存和击败。
- 胜利锁只结算一次。入场清普通障碍，胜利清弹幕和召唤物，演出期间保护玩家。致命受击先结算，不能同帧又拿生存胜利。
- 保留原战败规则：非血契1HP上限玩家保留1HP，20管后再战一次，二次战败跳章无礼包；跳章不记成功。回归战重新计时。
- 第二章结束仍沿用现有无尽飞行，不在本轮新增结局页面。

## 技能审查后的修复

1. 连击无敌要求实际持有连击之心，保留已有防永动约束。
2. 冰雹免疫检查先于防御资源消耗；避免同帧连耗护盾、缩短长无敌；致命冰雹与普通受击统一进入 Boss 战败保护。
3. 护盾获取统一经过 addShieldLayer，护盾爆发能兑现满级超载转临时HP；去除重复护盾特效事件。
4. 章节回响更新和消退同步 HP/护盾上限、银行与顿悟配置，且不额外领取即时回血/补盾。
5. 经验银行原本存取同帧、余额恒零。改为正常经验全额入账，额外存5%/级，下次升级先取历史余额再判顿悟，最后存本次本金。余额两位小数、取整提款保留余数、10秒生息5%/级、余额上限当前需求×2。旧卡面同步更新。
6. 左飞导弹正确离屏回收，防占用发射上限；满级雨衣积水速度下限0，不能生成负重力。
