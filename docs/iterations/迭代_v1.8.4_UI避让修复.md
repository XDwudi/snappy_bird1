# v1.8.4 UI避让修复

日期：2026-10-03；基线b6fc9c2，保持1.8.4版本与其全部平衡修订。

## 问题与修复

刘海屏safeTop=47时，旧Boss信息面板延伸到y=209，而上方树根中心y=190、血条y=163；再叠加天气面板，直接挡住目标。底部派系、无尽恢复和低血标签原先也会上浮进战斗区。

- 顶部统计与Boss名称/生命/生存计时合并，面板底边为safeTop+68；47/59px刘海屏分别止于115/127。顶部HUD先于敌人/机关/弹幕/玩家绘制，极端位置的对象仍可见，震屏保持相同层级。
- 招式与机关说明、天气/驯化、低血/穿盾提示放入screenH−80起的地面条。可读内容裁切到safeBottom；小安全区优先战斗信息，空间不够时不显示被动技能图标。
- 弹幕中的穿盾边框/菱纹仍保留，重复的悬浮文字面板改为底栏统一提示。低血边缘仍闪烁，文字不再挡在近地面战斗区域。
- 浮动文字优先最近6条，绘制时避开玩家、怪物、Boss与机关，以及已排布的文字；位置不足的旧提示不画。消息数据、生命周期与游戏状态不改变。
- 首页、3/4/6选卡、教学、转场、结算均检查；卡牌派系/章节/协同标签按可用宽度适配。暂停覆盖层保留，常驻HUD不会成为战斗中的遮挡层。
