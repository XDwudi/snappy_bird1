## 设计与实现

六Boss本体血量仍为135/235/410/680/1120/1750，未增加血量、全局接触伤害或压缩预警。保留击杀/生存双通关、每章140–190秒强制迎战、固定拍翅、经验递减及原关卡速度曲线。初期已有操作压力，本轮主要修复战斗的无效时间和卡牌收益。

| Boss | 机制收益 | 二阶段压力 |
|---|---|---|
| 古木守卫 | 每根6→3HP；双根/单根护甲倍率0.55/0.75；全破反噬20%本体HP，12秒受到1.75倍伤害，之后永久1.25倍；树根不复生 | 破根进入P2；根须阶梯追加第四次换层 |
| 遗迹巨蝎 | 成功诱撞的1.5倍易伤从3.5→8秒 | 地裂钳击追加一次错位夹击，中心只移动48px，间隔100帧 |
| 月蚀蛛后 | 破卵/阻止孵化沿用 | 蛛网两门→三门，缺口138→148px、错位76→60px；增加连续操作而保留单指可达路线 |
| 冰川魔像 | 蓄热范围68→96px；离框每帧损失2→1；三次蓄热后易伤8秒；常态伤害倍率0.5→0.65，每次碎甲再永久+0.1，上限1 | 反弹冰棱增加中央弹道；冻层追加第四段；P2冰门双波 |
| 熔岩地龙 | 同样扩大开阀窗口、减慢离框回退；破熔核易伤8秒 | 熔岩弧线三发→五发，错开发射；热量喷发仍与开阀相互制约 |
| 风暴机核 | 按序破三节点后易伤10秒，节点不重生，核心永久失防 | P2引力门两次错位穿越；穿盾至少90帧预警 |

修复连招索引：原攻击次数同时用来选下一组组合，组合长度不同会跳过部分组。现在独立轮换组合，每组都会出现。机关直伤跨越半血也立即触发P2，预警发出后仍不改变该招几何。输出窗口显示剩余秒数；树根/节点永久破坏有明确文字反馈。绿框绘制同步实际96px判定。

参考[Supergiant《Hades》Big Bad更新说明](https://www.supergiantgames.com/blog/hades-big-bad-update-patch-notes/)：官方同时调整Boss攻击、追踪、前后摇、无敌时间，也会移除负作用、替换技能。这里借鉴的是“威胁强度与玩家可反击性分别调整”的方法，而非照搬它的数值。落实为永久破甲进度、较长输出窗口，以及有预警的后续波次。

## 技能审查

逐条核对73张卡的等级文本、章开放与效果入口；没有通过删除大量卡来解决数值问题。以下是本轮实际改动，其他卡保留原设定，并继续由历史回归覆盖已建立的契约，不宣称73张卡都已达到真人最优平衡。

| 技能 | 问题 | 处理 |
|---|---|---|
| 疾风羽刃 | 后续等级只加攻速，后期直射收益低 | 每级怪物伤害1/2/3，Boss2/3/4；保留2.5/2/1.5秒间隔与需要对准的特点 |
| 顺风 | 无武器时无用，五次选择仅15%间隔收益 | 有自动武器才进池；三级，每级间隔-6%，总计-18%；不改变拍翅 |
| 连击种子 | 没有连击之心时无有效收益，高等级又经常被阈值上限截断 | 需连击之心；仅保留一级，取消重复无效升级 |
| 蚀影毒丝 | 高频命中反复把跳伤计时重置为60帧，攻速越快可能越不出毒伤 | 只续持续时间，保留下一次跳伤时钟；不叠毒 |
| 暗影复射/毒丝/天雷链路 | 没有弹丸来源也会出现 | 需持有弹丸武器；仅有熔核/坍缩等范围伤害不算前置 |
| 余烬处决 | 没有对应武器也会出现 | 需任一自动武器，包括范围武器 |
| 天雷链路 | 单体Boss无第二只小怪时不产生实际收益 | 优先传导到另一敌人；单体Boss时对本体放电，伤害等级+2，冷却1秒、不递归；机关不触发 |
| 御风者 | 无风，尤其Boss期间没有风时整张卡失效 | 无风每7/6/5秒双刃；有风仍5/4/3秒，保留天气收益 |
| 旅者/章节回响 | 第六章及无尽新抽到后没有下一章可触发 | 第六章起不再作为新候选；已有进章收益保留 |

前置筛选统一作用于普通升级、幸运替换、史诗保底、Boss礼包四类入口。保留稀有度、章解锁与派系系统；能力总数仍73张。经济卡不直接送战力，纯经济选择可能导致短期生存失败；信息类和计分类保留用途差异，不把每张卡都变成同质伤害加成。拍翅和防御恢复规则未改，避免强化输出又变成全程无敌。

## 模拟方法与结果

`test/sim_v184.js`调用真实Game.update：自然经验、自然候选、无注入满级技能、无额外回血、无跳章。观察间隔8–12帧、拍翅决策延迟6–10帧、瞄准误差±12px，最小拍翅间隔12帧；约每10秒3%机会漏操作18帧。仅读可见预警与粗略直线投影，不读取未来招式或未显示的后续波次。三种策略只从实际发出的牌里选择：围绕武器、随机、偏经济。每种64个固定种子，改前/改后各192局，单局上限2200有效秒，进入无尽后最多再跑300秒。

这些是未用真人数据校准的脚本假设，仍会比人更快地比较多个危险位置；不代表真人胜率。改卡池会改变后续随机路径，相同种子不是完全相同遭遇，因此另做固定装备Boss对照。

| 路线（各64局） | 第一章击杀：前→后 | 第一章生存：前→后 | 六章全通：前→后 | 后版60秒内死亡 |
| 围绕武器 | 23→41 | 3→0 | 1→4 | 7/64 |
| 随机选择 | 4→20 | 14→0 | 0→0 | 7/64 |
| 偏经济 | 4→16 | 6→0 | 0→0 | 7/64 |

结果支持“第一关可以通过输出推进、选择武器形成正反馈、纯经济仍有风险”，不能据此保证后期已经完全平衡。

固定装备复测（`test/probe_v184.js`）从旧版自然局提取装备，每章最多12套，改前/后使用相同装备及种子；为隔离Boss，开战满当前HP/护盾、不继承旧局祝福和冷却，属于独立战斗测试。旧版/新版的同一卡按各自等级上限装配。共45套，结果如下；击杀耗时仅统计各版本击杀局，并非相同幸存子样本。

| 1 | 12 | 6→11 | 80.5→32.3 | 73%→25% |
| 2 | 12 | 11→12 | 41.9→38.2 | 0%→0% |
| 3 | 8 | 8→7 | 71.9→68.7 | 0%→0% |

第五/六章分别只有1/3套旧版自然装备样本，数据不足以验收整体难度；冰川改善来自解除不合理的长期护甲和增加机关可操作空间。风暴战因完整轮换连招，耗时反而增加，没有统一把所有Boss变成短战。
