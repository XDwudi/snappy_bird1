## 1. 范围与入口

依据[玩法审查1.8.5](../audits/玩法审查_v1.8.5_2026-10-03.md)、[1.9.0提案](提案_v1.9.0_玩法体验优化.md)及[73卡附表](附表_v1.9.0_技能槽位与协同迁移.md)开发。原文保持候选方案身份，不把设计中的12人测试目标当成已完成结果。保留1.8.6针对v185-review的碰撞顺序、胜利保护、残水、分数小数和生机收割修复。

新增主要模块：`BuildConfig`（槽位、配方、来源与迁移）、`BuildSystem`（候选/投资/换装事务）、`Progression`（奖励和休息流程）、`Selection`（选卡交互）、`Checkpoint`（章间续局）、`RunClock`（固定步长）、`Random`（可存储的局内随机序列）。删除旧Game中的叠加祝福和无限all-buff入口，正常升级与Boss成长共用构筑规则。

## 2. 构筑、卡牌与成长

- 单局3组件＋6被动；开局羽刃Lv1计入组件；1主专精，最多2项进化。主题派系仅作来源标签，不再自动给2/4卡属性收益。
- 73个历史ID全部有迁移记录：11组件、60被动、管感/先知转免费信息，共71张可获取卡。卡面默认显示配方进度；管道轮廓为基础能力。运行时逐卡等级、前置、来源、互斥与效果见[迁移表JSON](../audits/v190/card-migration.json)。
- 普通上限`min(旧上限,3)`。原5级收益按1/3/5映射到新1/2/3级；原1/2级卡不扩级。
- 六路线：对线标记强化、周期导弹齐射、拦截蓄层反击、过管/真实擦边充能、霜毒反应、个人风窗强化风刃。第一Boss后选主专精，第三Boss后选分支。分支卡面列出实际触发或数值。
- 核心3＋支援2开启进化；羽刃贯穿/扇射二选一。第二项进化第4章开放，明确显示在配方提示中；临时章节回响不计永久进化门槛。
- 每局2重掷；普通候选优先已有核心升级，其次协同/生存和探索。所有额外幸运候选均受槽位/前置/等级限制。重掷不推进面板保底，也不丢失当次史诗保证。
- 章节之主第2章开放，取得后下次及后续每章首面板保证合法史诗；没有可兑现的后续史诗时不新发这张卡。旅者/章节回响在末章和无尽不再新发。
- 每局2次章间调整；可同时替换一个组件和一个被动，总等级等额转移、单卡不超上限。预览依赖/专精/进化损失后提交；需更换专精时并入同一事务。进化失效返还一次投资，凤凰/求生/顿悟/驯化账本不重置，换入活力不即时回血。取消或非法事务不扣资源。
- 派生弹、毒、反射和连锁使用明确来源，不能递归触发其他基础命中链。范围攻击能破根/卵，但不能跨越风暴节点。穿盾和区域危险不可被守卫/清弹吞掉。
- Boss原45帧同源门限改为发射批次预算（导弹24、其他18）；记录命中、尝试伤害、实际伤害和限幅。挂架多弹有实际收益，下一批不被上一批门限吞没。

成长基础经验70、每级增量18、20级后保留二次曲线。普通选择间隔至少6秒有效飞行。为防经济流继续连续选卡，每章累计释放上限为8/14/19/24/29/35次（含各Boss一次成长），提前预留Boss奖励；多余经验完整留在待选银行，HUD显示待选/下章。无尽解除章节释放上限，但仍受6秒间隔及装备容量约束。

每Boss只有一次成长选择，另自动给100基础分、1HP和1盾（服从容量/恢复冷却），不再叠加固定一级经验、稀有卡与祝福。满配后组件最多各突破3次：伤害组件每次+1伤，护盾爆发每次周期-5%；随后转最多10秒一份恢复补给，满容量/冷却中改为10基础分。旧无限属性成长取消。

## 3. 六章机关

| Boss | v1.9.0实际规则 |
|---|---|
| 古木守卫 | 上根连接飞种、下根连接根须；各自减少对应攻击，双根永久破坏和易伤，有连线/文字标识。 |
| 遗迹巨蝎 | 独立追踪准备、最后1秒锁定、冲锋和撞柱；柱区标为诱撞目标，锁定后不追身；P2第二段重新预告和锁定。优先约8秒后安排下一次诱导，具体开始受前一招完成时间影响。 |
| 月蚀蛛后 | 同屏2卵，上卵孵化为短时封区，下卵为2枚追踪弹；倒计时可见，P2改变上卵位置和倒计时。追踪武器结合高度、距离和当前可攻击性选择目标。 |
| 冰川魔像 | 删除45帧上下打卡；缓移暖流累计3秒碎冰，离开0.8秒内保留、之后缓慢衰减；已完成碎冰永久减甲。显示后续方向；P2缩窄暖流，冻层仍提前预告。 |
| 熔岩地龙 | 双阀预告1.5秒、开放2秒；须从外进入，一轮只能选一个，开窗已在内部需先退出；瞬移不能触发。冷却降低热量并取消下一次满热喷发，超载增加热量换5秒易伤，并追加预告地火。 |
| 风暴机核 | 三种可达顺序模板，当前/下一节点同时可见；未来节点不吸弹，范围攻击不能跳序；每个节点永久关闭对应磁轨，三路断开后失防。 |

飞行最早90/95/100/105/110/115秒，最迟105/110/115/120/125/130秒；Boss生存55/60/65/70/75/80秒。剧情血量150/230/320/430/540/660，P2按半血或55%时间触发。六章结束明确提供“结束本局”或“继续无尽”。

## 4. 交互、存档与计时

升级误触采用同一套交互覆盖普通升级、幸运6卡、专精、进化、休息和换装：

1. 卡牌列表滚动，点击只预选；确认按钮固定在安全区底部，卡牌不会铺进按钮区域。
2. 新面板350ms内不接受新触摸，确认须距预选至少250ms；不开默认选项。
3. 滚动超过8px、取消、多点触摸、开窗前按住或跨面板松手均不提交。只露出不足24px的卡片边缘不可预选。
4. 选完恢复短保护并清零垂直速度，待选经验不会连弹多层。

8秒出现无接触伤害的2HP训练靶，奖励只发一次且不触发收割/拾荒；15秒起允许普通怪。提示依次介绍拍翅、目标高度、擦边风险、首Boss根源，不堆叠完整说明书。

章间保存会保留原候选、随机状态、装备、进化、专精、待选经验、奖励阶段、冷却、一次性资源与天气实体；主页提供继续入口。选择后立即更新章间记录，不能靠重开重复领取同一Boss奖励。离开休息点继续飞行后清除旧检查点，避免回滚刷战斗；本版不提供战斗中断点恢复。保存失败显示重试提示。

局内记录带`1.9.0`规则版本；旧规则存档拒绝混载。新最高分独立存储，原最高分键保留供历史读取。战报保存主专精、组件、进化、章节、真实事件、死亡来源和建议。

逻辑按60Hz固定步长、渲染随设备rAF。30/60/120fps推进一致；后台停止逻辑，不补跑离线时间。单帧超过250ms的额外停顿计暂停，避免长卡顿后突进。分别记录飞行、Boss、读卡、演出、暂停和无尽。

## 5. 验证与限制

74项通过：32条新规则/交互/存档事务测试、12条沿用1.8.6关键修复的生命周期回归、10条弹丸轨迹/来源回归、16种固定拍翅路径组合、4种屏幕的Canvas检查。运行JS语法及打包检查通过。主包2,907,195字节、资源分包3,822,682字节；之后微小文档/提示变更以[包体报告](../audits/v190/package.json)为准。

证据边界必须区分：

- [108场Boss矩阵](../audits/v190/boss-matrix.json)：六路线×六Boss×仅卡牌/专精/进化三个处理组，19级卡牌投资相等；屏蔽扣血以隔离输出、机关和危险暴露，**不是108场真人胜利**。含来源伤害及限幅数据；导弹路线在该模型中击杀能力仍偏强，守卫与擦边的价值需实机操作验证。
- [12组完整成长探针](../audits/v190/progression-probe.json)：屏蔽致死伤害、经验和候选正常，每次读卡3秒。首章7–8次、终章35次；六章加模拟读卡/演出约17.0–19.6分钟。大部分首次进化在2–3章，少量最早1章；第二项需要玩家确实投资另一个配方，样本未保证人人两项。此数据没有测真人P90，也没有把假定5–8分钟无尽算成实测。
- [48局自然模型](../audits/v190/natural-runs.json)：保留真实伤害和有限反应延迟，最远第3章，无六章完整胜利；连贯/随机/经济策略有效时长中位80/56/45秒。早期失败风险仍需手机/真人调查，不能由屏蔽伤害的探针掩盖。控制器依据固定拍翅约67px的上升行程修正了旧模型向目标上方偏飞的阈值；[旧控制器数据](../audits/v190/natural-runs-prior-controller.json)保留，未选择性删除失败样本。
- [物理可达性](../audits/v190/reachability.json)：4种尺寸×2初始高度×2初速度，暖流及两阀高度可达；**没有证明每一种叠加弹幕都可无伤躲避**。
- [多屏截图](../audits/v190/selected-320.png)、[六Boss](../audits/v190/six-bosses.png)、[战报](../audits/v190/report.png)：离线真实Canvas，非微信设备截图。
